# Bad Apple!! but on a keyboard

This was made using the [K70 CORE RGB Keyboard](https://www.corsair.com/us/en/p/keyboards/ch-910971e-na/k70-core-rgb-mechanical-gaming-keyboard-black-ch-910971e-na)
and the [iCUE Software](https://www.corsair.com/icue).


## Installation

### You must have the [iCUE Software](https://www.corsair.com/icue) to run this program.
* Download the software
* Once open, make sure your compatible keyboard (such as the [K70 CORE RGB Keyboard](https://www.corsair.com/us/en/p/keyboards/ch-910971e-na/k70-core-rgb-mechanical-gaming-keyboard-black-ch-910971e-na))
is listed as a device in the home page
* Go to Settings then SDK and allow iCUE SDK and Game SDK. Here you can also control the keyboard

## Usage

Run the program and input the length of the video in seconds [integer]. This program does not use a video file as input, but rather
images of each frame found in the [frames directory](frames).

The Bad Apple!! PV length in seconds is 209
